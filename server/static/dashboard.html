Workstation agent

Download for a new PC

  1. On the new PC, create a folder (e.g. C:\MeetingAgent) and save both files in it: OfficeMeetingAgent.exe · config.json (pre-filled with this hub)
  2. Run the .exe; it asks only for the person's name, then shows the caption strip and a tray icon.
  3. Optional: right-click the tray icon → Start with Windows is not built in; put a shortcut in shell:startup.

Publish a new build

Build on any Windows PC with Python 3.11/3.12: client\build_exe.bat → client\dist\OfficeMeetingAgent.exe, then upload it here. Everyone downloads this copy.
