      Odoo

      Publishes each meeting's minutes as a task, with one sub-task per action item assigned to its owner. Leave empty to keep minutes on the hub only.

      On the same server as the hub: http://host.docker.internal:8069
      Odoo, Preferences, Account security, New API key
      The number after /project/ in the project's address in Odoo
      One per line, caption name = Odoo name. For example: Ginadomenico = Gian Domenico Bianchi

      Noise and same-room microphones

      Sentences quieter than the background noise level are treated as room noise, which stops speech recognition from inventing phrases like “Thank you.” over silence. When two computers in one room hear the same sentence, only the louder microphone's caption is kept.

      0.005 suits most rooms. Raise it if captions show things nobody said; lower it if quiet speakers are missed; 0 turns it off.
      0 shows captions at once and turns this off
      0.78 tolerates small recognition differences

      Install the agent

      On a new computer

      The agent sends the microphone to this hub and shows everyone's captions. About a minute per computer.

      Download the agent Download settings file
      1. Put both files in one folderFor example C:\MeetingAgent. The settings file already points to this hub.
      2. Open OfficeMeetingAgent.exeIf Windows says the publisher is unknown, choose More info, then Run anyway. Type your name as it should appear in captions.
      3. Join meetings from the tray iconCaptions appear in a small strip at the bottom right. Pause, change meeting or write the minutes from the tray icon.

      Update the agent for everyone

      Only after the agent's code changes. Build it on a Windows computer with client\build_exe.bat, then upload it here.
