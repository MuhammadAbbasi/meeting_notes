        Settings

        Changes apply to every workstation as soon as you save. Use “Check connection” to try values before saving.

        Speech recognition

        Turns everyone's microphone audio into captions. Runs on the hub's GPU (WhisperLive).

        Minutes writer

        The language model that turns a transcript into minutes with decisions and action items. Uses the Ollama already running on the server.

        Odoo

        Where the minutes are published: one task per meeting, plus a sub-task per action item assigned to its owner. Leave empty to only keep the minutes on the hub.

        Captions

        When two PCs in the same room hear the same sentence, only the louder microphone's caption is kept.

        Defaults for new PCs

        Pre-filled in the configuration that new PCs download. Each person can still change them.

        Install the agent on a PC

        The agent streams the microphone to this hub and shows the captions. Takes about a minute per PC.

        Download OfficeMeetingAgent.exe Download config.json
        1. Create a folder on the PC, for example C:\MeetingAgentSave both files into it. config.json already contains this hub's address and the default meeting.
        2. Start OfficeMeetingAgent.exeWindows may warn that the publisher is unknown: choose “More info”, then “Run anyway”. The agent asks for the person's name as it should appear in captions.
        3. Use the caption strip and the tray iconThe strip sits bottom-right, half transparent, and can be dragged or hidden. The tray icon pauses or stops streaming, changes meeting, and writes the minutes at the end.

        For maintainers

        Needed only when the agent's code changes. The agent is built on a Windows PC with Python 3.11 or 3.12 (client\build_exe.bat) and uploaded here; every PC downloads this one copy.
